CacaoGuard System Documentation
System Overview
CacaoGuard is a web-based platform that helps cacao farmers detect diseases and pests using AI, with an integrated marketplace for cacao products.

Key Features
AI Disease Detection: Upload cacao leaf/fruit images for instant analysis

E-commerce Marketplace: Buy and sell cacao products

Farm Management: Map and track farm locations

Role-based Access: Three user types with different capabilities

User Roles
Farmer/User
Unlimited disease scans

Purchase products from marketplace

Track orders and scan history

Manage farm locations

Personal dashboard

Guest
5 scans per day (limited)

Browse marketplace (view only)

No purchase capability

Basic system exploration

Admin
Full product management (add/edit/delete)

Process and track orders

View all user scans and analytics

User account management

System monitoring

Core Functionality
Disease Detection
Upload JPG/PNG images of cacao plants

AI analysis identifies diseases and pests

Treatment recommendations provided

Scan history saved for registered users

E-commerce Features
Product browsing and search

Shopping cart and checkout

Multiple payment methods (COD, GCash)

Order tracking (pending → confirmed → shipped → delivered)

Farm Management
Mark farm locations on interactive maps

Track scans per farm location

Farm-specific statistics

Technology Stack
Frontend: HTML5, CSS3, JavaScript, TailwindCSS

Backend: Python Django 5.1

Database: Firebase Firestore

Storage: Cloudinary CDN

Authentication: Firebase Auth

Hosting: Render Cloud

Key Benefits
Early Detection: Identify crop issues before they spread

Market Access: Direct marketplace for cacao products

Data Tracking: Monitor farm health over time

User-Friendly: Simple interface for all technical levels
